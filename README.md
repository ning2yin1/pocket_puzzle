# ぽけっとパズルの森

**つなげて そだてる ふしぎな島** — iPhone縦画面向けのマッチ3 PWA試作版です。既存の画像素材をすべて使っています。タイトル画像に含まれるロゴを生かし、操作ボタンはHTMLで表示します。

## 手元で起動する

Node.js 22以上をインストールして、このフォルダーで次の順番に実行します。

```sh
npm ci
npm run dev
```

表示されたアドレスを開きます。開発サーバーではService Workerを使いません。オフライン動作を確認する場合は、本番ビルドで確認します。

```sh
npm test
npm run build
npm run preview
```

ブラウザー自動テストは `npm run test:browser` です。ビルドを先に行ってください。Chromiumが `/usr/bin/chromium` にない環境では `CHROMIUM_PATH` に実行ファイルのパスを設定します。ブラウザーテストはGitHub Pagesと同じ `/pocket_puzzle/` 配下で実行します。

## GitHub Pagesへ公開する

1. GitHubのリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。
2. この変更を `main` にコミットしてpushします。
3. リポジトリ上部の **Actions**、または [Test and deploy PWAの実行一覧](https://github.com/ning2yin1/pocket_puzzle/actions/workflows/pages.yml) で成功を確認したら、**Settings → Pages** に表示されるURLをiPhone Safariで開きます。
4. 森の画面が表示され、オフライン準備完了のメッセージが出るまで待ちます。Safariの共有ボタンから **ホーム画面に追加** します。

HTTPSまたはlocalhostがPWAの条件です。初回は通信が必要です。初回に全19画像とアプリをキャッシュし、その後は3ステージすべてオフラインで遊べます。更新ファイルがある場合は通知されます。ゲームを保存してPWAと関連Safariタブを閉じ、開き直すと更新されます。新しいService Workerの有効化で、このゲームの古いキャッシュを削除します。他サイトのキャッシュは削除しません。

既存のGitHub Pages公開ワークフローを維持しています。修正後のSafari/WebKit実機で、ホーム画面追加・セーフエリア・音声・処理速度を最終確認してください。Safariのサイトデータ削除やOSによるストレージ削除でセーブが失われる場合があります。クラウド同期はありません。

## 遊び方

隣接する果実をスワイプ、または2つのマスを順にタップして交換します。3個以上で消去。無効な交換は元に戻り、手数は減りません。特殊アイテムは単独タップでも1手で発動します。演出中は入力を受け付けません。

| マッチ                | 生成アイテム | 単独効果                                       |
| --------------------- | ------------ | ---------------------------------------------- |
| 横4個                 | 横ロケット   | 1行                                            |
| 縦4個                 | 縦ロケット   | 1列                                            |
| L/T字など横・縦の交差 | TNT          | 中心から縦横2マス、最大5×5                     |
| 2×2                   | プロペラ     | 中心・上下左右＋優先目標1マス                  |
| 5個以上直線           | レインボー   | 交換した果実の色全体。単独タップ時は最も多い色 |

大きなマッチでは5直線 → 交差 → 4直線 → 2×2の順で判定します。生成位置は交換先を優先。自動連鎖時はグループ内の中央付近です。消去に巻き込まれた特殊アイテムも連鎖します。目標優先のプロペラは障害物、未達成の果実、その他の順に着弾先を選びます。

| 組み合わせ（順不同）              | 効果                               |
| --------------------------------- | ---------------------------------- |
| ロケット＋ロケット                | 交差する1行・1列                   |
| ロケット＋TNT                     | 3行・3列                           |
| TNT＋TNT                          | 最大7×7                            |
| プロペラ＋ロケット                | 周囲を消し、目標でロケット発動     |
| プロペラ＋TNT                     | 周囲を消し、目標でTNT発動          |
| プロペラ＋プロペラ                | 周囲を消し、目標3マスへ飛行        |
| レインボー＋ロケット/TNT/プロペラ | 最多色を相方の特殊に変え、一斉発動 |
| レインボー＋レインボー            | 全盤面                             |

これは本作の明示的な試作仕様です。ロイヤルマッチの完全な再現は意図していません。

木箱は隣接消去または特殊効果で、岩は特殊効果でのみダメージを受けます。障害物は1回の消去波につき1ダメージ。耐久値と配置はステージデータで設定します。落下は障害物と盤面外のマスで区切り、その各区間の上から補充します。手がなくなるとピースをシャッフルします。

初回クリアで60コインを獲得。ハンマーは20コインで指定マスを1回攻撃し、手数は使いません。ヒントは無料です。タイトルの「はじめる」は進行を消さずマップへ移動します。途中の盤面は、マップで同じステージを選ぶと再開できます。やりなおしは現在ステージのみを新しい盤面で始めます。

## ステージとキャラクター

| ステージ           | 手数 | 目標                             | 解放             |
| ------------------ | ---- | -------------------------------- | ---------------- |
| 1 はじめての果実   | 24   | いちご15・青りんご15             | ぴよ・みどりん   |
| 2 ふしぎなきらめき | 26   | バナナ22・ぶどう22、初期特殊あり | ぴんく           |
| 3 森のおかたづけ   | 32   | 木箱4（HP1）・岩4（HP2）         | くろまる・ふわり |

もちは最初から解放済み。クリア済みステージは再挑戦できます。キャラクター解放条件・エリアID・行列数・任意形状のマスク・目標・初期特殊・障害物は `src/stages.js` で管理します。エリアを増やす際にはマップUI側にもエリア切替を追加してください。

## 技術選定

Phaserも検討し、この小規模な試作ではCanvas 2Dと通常のHTMLを採用しました。ゲームロジックをフレームワークから独立させ、タッチ操作・小さな画面・静的配信に必要な機能を直接実装しています。ランタイムの外部ライブラリやCDNは不要です。描画解像度は最大2倍、演出の時間と連鎖回数には上限を設けています。ピクセル状の盤面はSafariでの互換性のため基本Canvas命令で描画しています。

## ファイル構成

- `src/engine.js`: DOMやCanvasに依存しない盤面・交換・マッチ・特殊・落下・目標処理
- `src/renderer.js`: Canvas描画、交換・消滅・落下・ロケット・爆発・飛行・光線・連鎖・クリア演出
- `src/main.js`, `src/style.css`: 画面、Pointer Events、セーフエリア、スクロールしない可変レイアウト
- `src/stages.js`: 3ステージと6キャラクターの設定
- `src/save.js`: localStorage、バージョン1の保存データ、不正JSONの復旧、保存失敗の通知
- `src/audio.js`: ユーザー操作後に開始するWeb Audioの簡易BGMと効果音
- `src/assets.js`: 新しい果実・特殊アイテム画像の参照。縦ロケットは横ロケットの同一画像を90度回転。内部の `tnt` 型には `bomb.png` を使用し、ゲームルール・セーブ形式は維持
- `src/layout.js`: 背景画像の拡大・トリミング座標、台座の原画像座標、タイトルのキャラクター範囲
- `assets/`, `assets-manifest.json`: GitHubにアップロードされたPNG素材19枚と実際の寸法・透過情報。背景画像は変更しません
- `icons/`: 既存もち画像をそのまま配置したPWA用アイコン
- `manifest.webmanifest`, `vite.config.js`: PWAメタデータ、本番ビルド時の全ファイル事前キャッシュと内容に基づくキャッシュバージョン
- `tests/`: ロジックテストとタッチ操作・画面サイズ・進行・保存・オフラインのブラウザーテスト
- `.github/workflows/pages.yml`: テスト・ビルド・Pages公開

## 検証範囲と制限

ロジックテストは全ステージ100種類のシード、生成条件、15種類の組み合わせ（ロケット2方向を別扱い）、連鎖、耐久、無効交換、手数、盤面形状、シャッフル、セーブを検証します。ロジック・素材・座標のテスト41件、ブラウザーテスト8件を実行しています。ブラウザーテストはChromiumのモバイル設定で短いSafari表示領域の320×460〜430×932を確認し、実際のタッチ交換・再開・オフライン操作・クリア時の進行更新を検証します。クリア画面のUIテストは終了直前の盤面を使うため、全ステージを自然プレイでクリアする難易度テストとは別です。

タイトルのキャラクターとボタンの非重複、台座と透明タップ領域の一致、背景が画面を覆うこと、セーフエリアの余白（上47/59px、下34px）の模擬検証も含みます。セーブのキー・バージョン1と内部アイテム型は変えていません。画面の高さは `100dvh` とSafariの `visualViewport` を併用し、背景とオーバーレイを同じ座標で更新します。

長時間の実機プレイによる難易度調整、Safari固有の表示・音声、実機FPSの測定は未実施です。BGMは短い合成メロディです。サーバー・課金・広告・オンライン同期は含みません。
